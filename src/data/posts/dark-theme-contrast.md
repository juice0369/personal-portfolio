## 为什么要算

深色主题很容易踩一个坑：浅色文字看着"够亮"，实际对比度可能只有 2:1，长时间阅读会累。WCAG AA 对正文的要求是 **4.5:1**，对大号文字和非文本元素是 **3:1**。

对比度不是凭感觉，而是按相对亮度公式算出来的：先把每个通道做伽马校正，再按 0.2126 / 0.7152 / 0.0722 加权求和，最后用 `(L1 + 0.05) / (L2 + 0.05)` 得出比值。

## 这个站点实测的结果

| 前景 / 背景           | 对比度    | 能否用于正文               |
| --------------------- | --------- | -------------------------- |
| `#F5F1E8` / `#0B0B0D` | 约 17.4:1 | 可以，远超 AA              |
| `#D8D2C4` / `#0B0B0D` | 约 13.1:1 | 可以                       |
| `#A9A29A` / `#0B0B0D` | 约 8.0:1  | 可以                       |
| `#C9A96A` / `#0B0B0D` | 约 9.5:1  | 可以，强调色也可以当文字色 |
| `#6B6459` / `#0B0B0D` | 约 3.4:1  | 不可以，只能做边框和图标   |

最后一行是这次唯一"踩到线"的地方：原本想用最深的灰做输入框边框，算出来只有 1.4:1，连 3:1 都不到。换成 `#6B6459` 之后才达标。

## 结论

**焦点指示统一用强调色。** 强调色对本背景有 9.5:1，无论做文字还是焦点环都够用，比灰色可靠得多。

凡是要用新颜色，先算一遍再写进代码，而不是看着顺眼就用。
